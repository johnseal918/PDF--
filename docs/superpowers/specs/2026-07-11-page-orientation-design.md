# PDF 页面方向设计

## 目标

导入 PDF 或图片时，按源页面宽高自动采用横向或纵向 A4 画布；用户可在编辑界面手动切换当前文档的横向/纵向，并保证预览与导出一致。

## 已确认交互

- 方向按钮放在中间画布底部现有控制条中。
- 顺序为：缩放控件、分隔线、方向按钮、上一页、页码、下一页、管理此页。
- 按钮显示当前状态：`横向` 或 `纵向`，使用现有 `QPushButton` 样式和密度。
- 不占用右侧已经拥挤的属性面板，不增加弹窗或新面板。

## 行为

- 导入时逐页读取源页面方向；宽大于高为横向，否则为纵向。
- A4 归一化使用与源页面相同方向的画布：纵向 `2480 × 3508`，横向 `3508 × 2480`。
- 一个文档中的页面允许保留各自导入方向。
- 点击方向按钮只切换当前页，将页面内容按比例居中放入目标方向 A4 画布。
- 已放置印章按页面宽高比例映射位置，避免切换后落到页面外。
- 切换后立即刷新预览；导出读取同一页面数据，不另建方向状态。

## 边界

- 本次不增加任意角度旋转、批量切换、多选页面或方向设置面板。
- 正方形页面按纵向处理。
- 不修改 iOS 工程。

## 验收

- 横向 PDF 导入后直接显示为横向，不再被塞入纵向 A4。
- 纵向 PDF 行为保持不变。
- 点击按钮可在横向、纵向间往返切换，按钮文字同步更新。
- 预览与导出的页面方向及内容位置一致。
- 现有测试与新增方向测试全部通过。
