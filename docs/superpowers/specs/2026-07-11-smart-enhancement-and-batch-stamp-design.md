# 智能增强与批量印章设计

## 目标

升级桌面端批量盖章流程：增加左栏快捷入口，明确两级印章尺寸同步，并以“智能增强文档”替换旧的去色降灰扫描引擎。

## 左栏快捷入口

- 左栏顶部增加两个等宽按钮：`打开文件`、`导出 PDF`。
- 素材库标题和内容整体下移。
- `打开文件`复用现有打开动作。
- 未加载文档时禁用`导出 PDF`；存在当前文档时启用并复用现有导出动作。

## 印章尺寸同步

印章右键菜单提供两个完整、无歧义的动作：

- `统一当前文档全部页面的印章尺寸`：以当前印章的真实 A4 尺寸为基准，统一当前 PDF 所有页面上的印章，不影响其他标签页。
- `统一所有已打开文档中的同款印章尺寸`：以当前印章的真实 A4 尺寸为基准，仅同步素材 ID 相同的印章，覆盖所有已打开 PDF 标签页，不影响其他素材。

## 智能增强文档

- 旧名称`启用底层去色降灰扫描引擎`替换为`智能增强文档`。
- 删除算法下拉框，不向用户暴露 Otsu、Adaptive、Manual。
- 关闭：保持原稿，不做去色、二值化、背景清理、细线增强或纸张噪声。
- 开启：自动清理背景，同时增强深色文字、表格和中浅灰工程线，并保护红章。
- 默认开启。
- 提供两个实时调节项：
  - `背景清理强度`：0–100，默认 50。
  - `细线保留强度`：0–100，默认 70。
- 滑块变化后复用现有约 250ms 防抖，只刷新当前页。
- 参数按 PDF 标签页独立保存；导出时用同一参数处理该文档全部页面。

## 增强算法边界

- 采用方案A的单一融合增强管线，不做整页文档类型分类。
- 强内容层：灰度阈值保留深色文字、粗线和表格。
- 细线层：局部对比度增强后，以自适应阈值提取中浅灰有效线条；`细线保留强度`同时控制局部窗口与合并权重。
- 红章层：处理前按色相、饱和度和红色优势提取原始彩色像素，处理后按原色恢复，不参与黑白阈值判断。
- 背景层：`背景清理强度`控制背景估计窗口和白化力度，只清理低局部对比度区域；结构化线条不得作为背景删除。
- 四层处理集中在 `CVProcessor.enhance_document()`，当前页预览、预取、批量应用、PDF导出和图片导出必须调用同一函数，不得各自复制算法。
- 不添加旧的随机纸张噪声，避免预览每次刷新不一致。
- 仓库自动化测试使用合成的浅灰工程线、黑字、表格、灰底和红章；两份用户提供的泵图 PDF 只用于本机哈希确认后的只读专项回归，不复制进仓库、不硬编码绝对路径、不写入或覆盖源文件。

## 状态、兼容与性能

- 旧模板字段 `mode`、`threshold`、`noise_intensity`、`red_preserve_strength`仍可读取；加载时迁移到新参数，保存时只写新字段。
- 关闭智能增强表示“不执行增强算法”；现阶段导出仍沿用既有页面栅格化链路，不承诺保留原 PDF 矢量对象。
- 实时预览以当前页显示尺寸处理或缓存完整结果；连续滑动时只有最新参数签名的结果可以回写，切换标签页后旧结果不得覆盖新页。
- 完整分辨率只用于最终应用与导出；实时预览目标为不阻塞窗口交互。
- 两种尺寸同步仅作用于普通印章，签名和骑缝章不参与。
- 当前文档同步覆盖当前 PDF 各页上的全部普通印章；跨文档同步仅覆盖与基准印章素材 ID 相同的普通印章。
- 尺寸基准使用未旋转印章宽度换算的 A4物理单位；横向、纵向页面使用各自页面到A4的比例换算。
- 每个受影响文档分别产生可撤销修改；没有匹配印章时显示明确提示。
- `打开文件`始终可用；`导出 PDF`只导出当前标签，未加载时禁用并提示`请先打开文件`，导出进行中防止重复触发。

## 方案比较

- 方案A（采用）：同页分层融合。优点是可同时处理文字、表格、工程线和红章；缺点是实现与测试成本较高。
- 方案B（拒绝）：整页分类后选择Otsu或Adaptive。实现较快，但用户样本本身是工程图、表格和文字混合页，整页误分类风险高。

## 验收

- 左栏按钮位置、启用状态和现有菜单动作一致。
- 两种尺寸同步的作用域与菜单文字一致。
- 关闭智能增强时，预览和导出保持原稿。
- 开启后，工程图泵体轮廓、尺寸线、表格和普通文字均清晰可辨。
- 合成样本与本机泵图专项回归必须同时验证：中浅灰有效线条保留率不低于80%，低对比度空白背景残留率不高于5%，深色文字/表格保留率不低于98%，红章区域平均色差不高于15（RGB通道平均绝对差）。
- 滑块实时预览，预览与导出结果一致。
- 机器断言按钮位于左栏顶部且默认可见；无文档、单文档、多标签、导出中和导出失败状态均有对应检查。
- 计划专用测试必须在删除任一快捷按钮、绕过共享增强函数、混淆两种同步范围或恢复旧Otsu默认链路时失败。
- 所有自动化测试通过，源 PDF 不被修改。
