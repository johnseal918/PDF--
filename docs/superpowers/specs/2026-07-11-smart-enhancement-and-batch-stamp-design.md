# 智能增强与批量印章设计

## 目标

升级桌面端批量盖章流程：增加左栏快捷入口，明确两级印章尺寸同步，并以“智能增强文档”替换旧的去色降灰扫描引擎。

## 左栏快捷入口

- 左栏顶部增加两个等宽按钮：`打开文件`、`导出 PDF`。
- 素材库标题和内容整体下移。
- `打开文件`复用现有打开动作。
- 未加载文档时禁用`导出 PDF`；存在当前文档时启用并复用现有导出动作。

## 印章尺寸同步

印章右键菜单提供两个完整、无歧义的动作：

- `统一当前文档全部页面的印章尺寸`：以当前印章的真实 A4 尺寸为基准，统一当前 PDF 所有页面上的印章，不影响其他标签页。
- `统一所有已打开文档中的同款印章尺寸`：以当前印章的真实 A4 尺寸为基准，仅同步素材 ID 相同的印章，覆盖所有已打开 PDF 标签页，不影响其他素材。

## 智能增强文档

- 旧名称`启用底层去色降灰扫描引擎`替换为`智能增强文档`。
- 删除算法下拉框，不向用户暴露 Otsu、Adaptive、Manual。
- 关闭：保持原稿，不做去色、二值化、背景清理、细线增强或纸张噪声。
- 开启：自动清理背景，同时增强深色文字、表格和中浅灰工程线，并保护红章。
- 默认开启。
- 提供两个实时调节项：
  - `背景清理强度`：0–100，默认 50。
  - `细线保留强度`：0–100，默认 70。
- 滑块变化后复用现有约 250ms 防抖，只刷新当前页。
- 参数按 PDF 标签页独立保存；导出时用同一参数处理该文档全部页面。

## 增强算法边界

- 强内容层：保留深色文字、粗线和表格。
- 细线层：通过局部对比度与自适应判断恢复中浅灰有效线条。
- 红章层：处理前提取，处理后恢复，不参与黑白阈值判断。
- 背景层：按背景清理强度抑制灰底和孤立噪声。
- 不添加旧的随机纸张噪声，避免预览每次刷新不一致。
- 两份用户提供的泵图 PDF 作为固定回归样本；测试不得写入或覆盖源文件。

## 验收

- 左栏按钮位置、启用状态和现有菜单动作一致。
- 两种尺寸同步的作用域与菜单文字一致。
- 关闭智能增强时，预览和导出保持原稿。
- 开启后，工程图泵体轮廓、尺寸线、表格和普通文字均清晰可辨。
- 在已提供源文件上，中浅灰细线保留率显著高于旧 Otsu 的 11.32%，且不能靠保留整页灰底达成。
- 滑块实时预览，预览与导出结果一致。
- 所有自动化测试通过，源 PDF 不被修改。
