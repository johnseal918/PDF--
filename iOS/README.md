# iOS 项目目录

本目录用于集中保存本项目后续所有 `iOS / iPadOS` 相关的开发资料、设计文档、技术方案、工程代码和上架材料。

## 目录约定

- `docs/`
  iOS 产品需求、PRD、技术方案、排期、评审记录
- `app/`
  iOS 工程代码、脚本、配置文件
- `resources/`
  图标、截图、原型图、上架素材、测试样例

## 使用规则

- iOS 开发相关的新文档，默认优先放在本目录下。
- 跨端共用的规则和业务说明，继续保留在项目根目录或桌面端文档中。
- 当 iOS 的入口、阶段或工程结构发生变化时，需要同步检查公开仓库 README。
