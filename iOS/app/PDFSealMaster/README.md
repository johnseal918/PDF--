# PDFSealMaster iOS 源码骨架

当前目录是按照 `iPhone 版开发方案 v1.2` 开始执行后的第一批源码。

这批内容的目标不是一次性做完整 App，而是先把第一阶段必须正确的业务骨架固定下来：

- `App/`
  SwiftUI 入口、路由、全局设置
- `Domain/Models/`
  文档、页面、印章、签名、编辑对象模型
- `Domain/Services/`
  `A4` 归一化、文档加载、印章规范化、草稿恢复服务协议与占位实现
- `Infrastructure/Repositories/`
  本地仓储占位实现
- `Features/`
  首页、主编辑页、印章导入页骨架

当前已执行：

- 正式开始 `M1`
- 把 `A4 + 真实尺寸 + 有效章面 + 草稿恢复` 这些硬规则写进源码模型
- 落了 iPhone 主编辑页和印章导入页骨架

当前未执行：

- `PDFKit` 真实预览
- 图片/PDF 真实导入
- 印章自动裁边与去底算法
- 骑缝章、签名复用、付费拦截
- Xcode 工程文件

这些会在后续继续沿着开发方案往下接。
